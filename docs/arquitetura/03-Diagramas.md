# Diagramas

## 1. Objetivo

Concentrar a lista dos principais diagramas e artefatos visuais do projeto, facilitando a localização dos materiais de apoio à especificação funcional e técnica.

## 2. Diagramas Previstos

### 2.1 Mapa Funcional

Visão macro dos módulos do sistema e das relações entre eles.

### 2.2 DER

Representação do modelo de dados do domínio, incluindo entidades, relacionamentos e tabelas de apoio.

### 2.3 BPMN ou Fluxogramas

Representação dos principais fluxos operacionais da aplicação.

### 2.4 Modelo de Certificado

Layout visual do certificado emitido ao final do treinamento.

### 2.5 Modelo de Importação

Planilha padrão usada para importação em lote de funcionários.

### 2.6 Wireframes

Protótipos ou telas de referência para navegação e validação de usabilidade.

## 3. Relação com os Anexos

Os diagramas e materiais visuais devem ser armazenados na pasta de anexos para manter a documentação principal leve e organizada.

## 4. Critérios de Uso

Os diagramas devem ser atualizados sempre que houver mudança relevante de escopo, regra de negócio, estrutura de dados ou fluxo operacional.
